# ESSENZA ESTÉTICA

Frontend da clínica de estética premium **ESSENZA ESTÉTICA**.

## Site publicado

https://kawehenri.github.io/ESSENZA_ESTETICA/

O deploy é automático via GitHub Actions a cada push na branch `main`.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Conteúdo editável

Textos, contatos e tratamentos ficam em `src/data/`.
Imagens geradas em `src/assets/images/`.
