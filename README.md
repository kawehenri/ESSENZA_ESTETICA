# ESSENZA ESTÉTICA

Frontend da clínica de estética premium **ESSENZA ESTÉTICA**.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Conteúdo editável

Textos, contatos e tratamentos ficam em `src/data/`.
Imagens geradas em `src/assets/images/`.
